# Стандарты экосистемы Wiren Board

Пакет стандартов на правила формирования имён, текстов и шаблонов в экосистеме Wiren Board.

Все три документа опубликованы под лицензией [CC BY 4.0](LICENSE): их можно свободно копировать, распространять и адаптировать при указании авторства (Wiren Board). Каждый документ версионируется независимо — версия и дата указаны в шапке документа и в его «Истории изменений». Ссылки между документами недатированные: применяется актуальная редакция; согласованный набор фиксируется состоянием репозитория.

## Состав пакета

| Документ | Тема | Область применения |
| --- | --- | --- |
| [WB-STD-001](<WB-STD-001 MQTT Топики.md>) | Идентификаторы MQTT-топиков | Любое ПО WB, публикующее в MQTT (драйверы `wb-mqtt-*`, `wb-rules`, веб-конфигуратор) |
| [WB-STD-002](<WB-STD-002 UI-тексты.md>) | Стиль текстов в пользовательском интерфейсе | Любые UI-тексты WB (веб-конфигуратор, MQTT-метаданные, шаблоны, `wb-rules`) |
| [WB-STD-003](<WB-STD-003 Шаблоны serial устройств.md>) | Шаблоны устройств для драйвера `wb-mqtt-serial` | Шаблоны `wb-mqtt-serial`; канонические группы |

## Иерархия зависимостей

```
   WB-STD-001         WB-STD-002
   (MQTT-имена)       (UI-стиль)
          \               /
           \             /
            ▼           ▼
         WB-STD-003
    (шаблоны wb-mqtt-serial,
     канонические группы)
```

WB-STD-003 ссылается на WB-STD-001 и WB-STD-002 как на нормативные источники общих правил. WB-STD-001 и WB-STD-002 независимы друг от друга и применимы вне контекста шаблонов `wb-mqtt-serial`.

## Внешние источники

- **[Wiren Board MQTT Conventions](https://github.com/wirenboard/conventions)** — публичные соглашения Wiren Board по MQTT. Раздел 1.2 «Naming Conventions (2024+)» — основа WB-STD-001; раздел 3 «Control Types» — основа типов каналов в WB-STD-003.
- **`wb-mqtt-serial-device-template.schema.json`** (в репозитории `wb-mqtt-serial`) — первоисточник структуры шаблона для WB-STD-003.

## Что подавать AI-агенту

| Задача | Требуемый контекст |
| --- | --- |
| Генерация шаблона `wb-mqtt-serial` | WB-STD-003 + WB-STD-001 + WB-STD-002 + JSON-схема шаблона + Conventions §3 (словарь units) |
| Генерация виртуального устройства `wb-rules` | WB-STD-001 + WB-STD-002 |
| Проверка имени MQTT-топика на соответствие конвенции WB | WB-STD-001 |
| Проверка или перевод UI-текста | WB-STD-002 |

Этого набора достаточно для решения соответствующей задачи без обращения к внешним ресурсам.
